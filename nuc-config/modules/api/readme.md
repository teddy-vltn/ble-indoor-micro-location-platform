Documentation de l'API Game
===========================

Prérequis
---------

*   Python 3.6 ou supérieur
*   Flask
*   Flask-Restx
*   Pymongo
*   MongoDB

Démarrage
---------

Pour démarrer l'API, exécutez la commande suivante dans votre terminal : `python3 main.py`

Ensuite rendez vous à l'adresse configurée et vous pourrez consulter tout les endpoints aux mêmes endroits.
