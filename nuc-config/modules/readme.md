# Modules

Vous pouvez retrouver tout les modules nécessaire au bon fonctionnement de l'environnement, tel que:
- Librairie afin d'intéragir avec la base de donnée
- API
- et Graph Positioning

## database

Gère toutes les fonctions permettant de créer des documents en base de donnée et permet un accès simple depuis
d'autre module à la librarie.

## api

L'api permettant par exemple au tableau de bord de fonctionner, et autre.

## graph-positioning 

Permet de positioner les joueurs dans le graphe et reconstruire leur trajectoire.
